## 1. System Requirements & Software Prerequisites

Ensure your system meets the following specifications before setting up the project:

### Primary Runtimes
1. **PHP 8.2 or 8.3** (Required by `composer.json` L9 and `Dockerfile` L2)
   - Enable mandatory extensions: `pdo`, `pdo_sqlite`, `mbstring`, `gd`, `zip`, `curl`, `xml`, `bcmath`, `exif`.
2. **Composer 2.x** (Required for PHP dependency management)
3. **Node.js 18+ / 20+ & npm 9+** (Required by `package.json` for Tailwind CSS v4 and Vite 7)
4. **SQLite 3** (Default local database driver)
5. **Git** (For version control)

## 2. Environment Configuration & Matrix

The application relies on `.env` for runtime configuration. Copy `.env.example` to create your initial configuration file:

```bash
cp .env.example .env
```

## 3. Step-by-Step Local Setup Guide

Follow these exact sequential commands from a fresh clone:

### Step 1: Clone the Repository
```bash
git clone <repository_url> forex_journal
cd forex_journal
```

### Step 2: Install PHP Dependencies
```bash
composer install
```

### Step 3: Install Node.js Frontend Dependencies
```bash
npm install
```

### Step 4: Environment Setup & Encryption Key Generation
```bash
# Copy example environment file
cp .env.example .env

# Generate application key
php artisan key:generate
```

### Step 5: Initialize SQLite Database
```bash
# Create empty SQLite database file
touch database/database.sqlite
```

### Step 6: Run Database Migrations & Seeders
```bash
# Run all 53 database schema migrations
php artisan migrate:fresh

# Seed default admin user, roles, trade accounts, strategies, and achievements
php artisan db:seed
```

### Step 7: Create Storage Symlink
```bash
# Link public storage directory to app storage
php artisan storage:link
```

### Step 8: Build Frontend Assets
```bash
# Build production JS/CSS assets via Vite
npm run build
```

### Step 9: Launch Development Servers
You can run servers using single commands or concurrently:

**Option A: Automated Single Command (Concurrently)**
```bash
composer run dev
```
*(This starts `php artisan serve`, `php artisan queue:listen`, `php artisan pail`, and `vite` simultaneously).*

**Option B: Manual Terminal Windows**
- **Terminal 1 (Backend API):** `php artisan serve`
- **Terminal 2 (Frontend HMR):** `npm run dev`
- **Terminal 3 (Queue Worker):** `php artisan queue:listen`

Access the web application at: **`http://127.0.0.1:8000`**

## 5. Setup Automation Scripts (Documentation Only)

Below are complete, copy-pasteable setup scripts for Unix/Linux/macOS Bash and Windows PowerShell environments.

### Linux / macOS Script (`setup.sh`)
```bash
#!/usr/bin/env bash
set -e

echo "=== Starting Forex Journal Setup ==="

# Check PHP
if ! command -v php &> /dev/null; then
    echo "ERROR: PHP is not installed."
    exit 1
fi

# Check Composer
if ! command -v composer &> /dev/null; then
    echo "ERROR: Composer is not installed."
    exit 1
fi

# Check Node
if ! command -v node &> /dev/null; then
    echo "ERROR: Node.js is not installed."
    exit 1
fi

echo "1. Installing PHP dependencies..."
composer install --no-interaction --prefer-dist

echo "2. Installing Node dependencies..."
npm install

echo "3. Setting up environment file..."
if [ ! -f .env ]; then
    cp .env.example .env
    echo ".env created from .env.example"
fi

echo "4. Generating Application Key..."
php artisan key:generate --ansi

echo "5. Preparing SQLite Database..."
mkdir -p database
touch database/database.sqlite

echo "6. Running Migrations and Seeders..."
php artisan migrate:fresh --seed --force

echo "7. Creating Storage Link..."
php artisan storage:link || true

echo "8. Building Frontend Assets..."
npm run build

echo "=== Setup Complete! Run 'composer run dev' or 'php artisan serve' ==="
```

### Windows PowerShell Script (`setup.ps1`)
```powershell
# Forex Journal Automated Setup Script for Windows PowerShell
$ErrorActionPreference = "Stop"

Write-Host "=== Starting Forex Journal Setup ===" -ForegroundColor Green

# Check Prerequisites
if (-not (Get-Command php -ErrorAction SilentlyContinue)) {
    Write-Error "PHP is not installed or not in system PATH."
}
if (-not (Get-Command composer -ErrorAction SilentlyContinue)) {
    Write-Error "Composer is not installed or not in system PATH."
}
if (-not (Get-Command node -ErrorAction SilentlyContinue)) {
    Write-Error "Node.js is not installed or not in system PATH."
}

Write-Host "1. Installing Composer Dependencies..." -ForegroundColor Cyan
composer install --no-interaction --prefer-dist

Write-Host "2. Installing NPM Dependencies..." -ForegroundColor Cyan
npm install

Write-Host "3. Configuring .env File..." -ForegroundColor Cyan
if (-not (Test-Path .env)) {
    Copy-Item .env.example .env
    Write-Host ".env created from .env.example" -ForegroundColor Yellow
}

Write-Host "4. Generating Application Key..." -ForegroundColor Cyan
php artisan key:generate --ansi

Write-Host "5. Creating SQLite Database..." -ForegroundColor Cyan
if (-not (Test-Path database)) { New-Item -ItemType Directory -Path database }
if (-not (Test-Path database\database.sqlite)) { New-Item -ItemType File -Path database\database.sqlite }

Write-Host "6. Running Migrations and Seeders..." -ForegroundColor Cyan
php artisan migrate:fresh --seed --force

Write-Host "7. Linking Storage Directory..." -ForegroundColor Cyan
try { php artisan storage:link } catch { Write-Host "Storage link already exists or failed non-critically." }

Write-Host "8. Building Frontend Assets..." -ForegroundColor Cyan
npm run build

Write-Host "=== Setup Complete! Launch with 'composer run dev' ===" -ForegroundColor Green
```

## 6. Troubleshooting Matrix & Common Solutions

| Issue Category | Error Symptom | Root Cause | Solution / Fix Command |
| :--- | :--- | :--- | :--- |
| **PHP Extension** | `PDOException: driver not found (SQLite)` | `php-sqlite3` extension disabled or missing. | **Ubuntu/Debian:** `sudo apt-get install php-sqlite3`<br>**Windows (`php.ini`):** Uncomment `extension=pdo_sqlite` and `extension=sqlite3`. |
| **PHP Extension** | `Call to undefined function imagecreatetruecolor()` | `gd` extension missing for image handling. | **Ubuntu/Debian:** `sudo apt-get install php-gd`<br>**Windows (`php.ini`):** Uncomment `extension=gd`. |
| **Database Lock** | `Database file is locked` | Concurrent process accessing SQLite database during seed/migration. | Terminate running `php artisan serve` or queue listeners, then execute `php artisan migrate:fresh --seed`. |
| **Vite Bundler** | `[vite] Failed to load PostCSS / Tailwind config` | Missing `@tailwindcss/vite` plugin or node module mismatch. | Delete `node_modules` and lockfile, then re-run `npm install`. |
| **Permissions** | `The stream or file "/storage/logs/laravel.log" could not be opened in append mode: failed to open stream: Permission denied` | Web server user (`www-data`) lacks write permissions on `storage` and `bootstrap/cache`. | Execute:<br>`chmod -R 775 storage bootstrap/cache`<br>`chown -R www-data:www-data storage bootstrap/cache` |
| **AI Coaching** | `Gemini Service: Gemini API Key is missing` | `GEMINI_API_KEY` not configured in `.env`. | Add `GEMINI_API_KEY=AIzaSy...` to `.env` or system environment. |
| **Windows OS** | `'concurrently' is not recognized as an internal or external command` | `npm install` failed or script path missing. | Run `npm install` directly in PowerShell, or run `php artisan serve` manually without `concurrently`. |
